# InfraDeck project brief

Self-hosted infrastructure inventory, project costs, reports and monitoring under AGPL-3.0-only.

The first beta supports a source build with Docker Compose. English is the default; Russian remains selectable. Ordinary SSH/Sentinel is available. Automatic S3 execution and SSH key rotation are experimental and disabled by default.

See README.en.md for setup, docs/architecture.md for architecture, docs/roadmap.md for plans and docs/releases/0.5.0-beta.1.md for release scope.

Design documentation and screenshots distributed publicly must use synthetic inventory only. The infrastructure illustration in docs/InfraDeck_Infrastructure.svg is a schematic example, not a live dashboard or production inventory.
