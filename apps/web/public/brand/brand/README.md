# InfraDeck — бренд-набор

Единая графическая система для веб-приложения InfraDeck.

## Структура
- `logo/`: горизонтальные и вертикальные логотипы, светлая/тёмная/монохромная версии, SVG и PNG.
- `icon/`: иконки для интерфейса и PWA, SVG и PNG 128–1024.
- `favicon/`: favicon.ico, PNG, Apple touch icon, PWA icons и пример webmanifest.
- `brand/tokens.json`: фирменные цвета и стек шрифтов.
- `examples/`: пример подключения в Next.js.

## Важно
Это специально подготовленная чистая векторная интерпретация ранее выбранной концепции (серверы + мониторинг + шестиугольник), а не автоматическая трассировка иллюстрации. Логотипы используют SVG text и зависят от установленного шрифта; для абсолютно одинаковой типографики на всех устройствах переведите текст в кривые в векторном редакторе. Файлы SVG — основной источник для масштабирования.

Рекомендуемый основной вариант: `logo/horizontal-dark.svg` для тёмного фона, `logo/horizontal-light.svg` для светлого. Для интерфейса: `icon/symbol-transparent.svg`.
