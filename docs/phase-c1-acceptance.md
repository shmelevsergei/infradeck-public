## Проверки

Текущая сессия: typecheck/lint/production build, 14 clean migrations, 23 domain/DB
и 7 E2E прошли. SSH regression проверяет отказ нового доступа с сохранением
старого и успешный add/verify/revoke с последующим отказом старому private key.
Реальный Python keyfile helper проверен в одноразовом контейнере: чужие строки и
ограничивающие options сохраняются. Это не заменяет живую приёмку sshd/sudo/apt
на согласованной внешней цели. Рабочий подключённый сервер не изменялся.

### Исправление После Подключения Реального Сервера

22.10.2026: на подключённом пользователем Linux-сервере подтверждены running агент,
network none, read-only root, отсутствие опубликованных портов, единственный
persistent mount `/app/db`. Текущие CPU/RAM/load/root disk поступают в worker.
Найден и исправлен HTTP 400 истории: закреплённый Sentinel требует UTC даты
`YYYY-MM-DDTHH:MM:SSZ`, без дробных секунд. Исправленный адаптер прочитал реальные
CPU/RAM ряды (по 19 точек на момент проверки), без изменения удалённого сервера.
Добавлен настоящий image API-тест фильтрованной истории и regression assertion
формата запроса. Страница метрик выбирает первый источник и график автоматически;
карточка показывает установленность агента/свежесть сбора и прямую ссылку на график.
Подтверждение последствий удаления стало обязательным browser-validatable checkbox.
Удаление проверяется только на синтетических объектах отдельной БД.
Полный bootstrap без Docker и STOP/restart на пользовательском сервере не выполнялись.
