# Public source provenance

This repository starts from a sanitized InfraDeck 0.5.0-beta.1 source snapshot with a new Git history. Documentation and illustrations contain synthetic inventory only. No production database, credentials, private design reference, or old Git history is included.

English is the default; Russian remains selectable. Automatic S3 execution and SSH rotation are experimental and disabled by default. Source-build installation is documented in README.en.md.
